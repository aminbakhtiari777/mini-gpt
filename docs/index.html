02

  • On-device model cache
  • Persian/English interface
  • Voice and file prototypes

ENGINEERING OUTCOME

The constraint became the result.

The browser model ran successfully, but a model small enough for reliable iPad execution was not strong enough for production-quality understanding. Larger models increased memory pressure and instability. Zamis documents that tradeoff instead of hiding it.
